
# email_extractor
This Python script securely connects to a Gmail account using OAuth2 authentication, eliminating the need for plain-text passwords. It accesses the Gmail inbox via the IMAP protocol and retrieves all available emails. For each email, it extracts the subject, sender address, and plain text body. The extracted content is then saved into individual `.txt` files within a specified local directory. The script is capable of handling both multipart and simple email formats, ensuring that only the relevant, non-attachment plain text is stored. It also automatically manages token storage and directory creation for streamlined and repeated usage.
